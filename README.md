# Math Star Feedback

A React Native / Expo case study for a children's math learning feedback flow.

## Features

- Practice completion entry screen
- Feedback screen with two performance states
- Details screen
- Rewards screen
- Mock data only, no backend

## User Flow

Practice Complete → See My Results → Feedback → Details / Rewards / Try Another Round

## Tech Stack

- Expo
- React Native
- Mock data
- React Native StyleSheet

## Run Locally

```bash
npm install
npm start
